# 🎯 Ulatus Website Counter Tool

Professional website content and image analysis tool for translation services.

## Features

- Single and multiple page analysis
- Full website crawl with depth control
- Word and character counting by language
- CJK detection
- Image analysis with alt/title checks
- CSV exports

## Installation

```bash
pip install -r requirements.txt
playwright install chromium
```

If you deploy on Streamlit Cloud, keep `packages.txt` in the repository.

## Run

```bash
streamlit run app.py
```
